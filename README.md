# Marmik Animal Welfare Foundation – Website

Static single-page website (HTML + Tailwind CDN). No build step.

## Edit contact details
Open `index.html`, search for `const CFG` and change the phone (country code, no `+`) and email.

## Deploy with GitHub Pages
Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
The site will be live at `https://<your-username>.github.io/<repo-name>/`.
